# 文档目录

该目录用于存放 PL2Android 对应的产品需求、设计说明和 Android 落地方案文档。

## 文件说明

- `一、移动端开发需求（App）.md`：移动端 App 原始需求拆解，覆盖登录、设备、媒体、预警、SOS、日报、推流、对讲、版本更新等模块。
- `执法耳机 App 产品需求文档 (PRD) - 需求重构与方案补全.md`：产品信息架构、页面清单、页面跳转关系、移动端专属能力和产品化建议。
- `执法耳机 App UIUX 设计方案说明书 (第二阶段).md`：视觉规范、核心页面设计、通用组件规范和 Compose UI 落地建议。
- `执法耳机 App 前端开发落地方案 (第三阶段).md`：Android 技术栈、项目架构、核心模块封装、硬件系统能力和开发里程碑。

未纳入 `1/`、`2/`、`3/` 目录下的 HTML、截图和生成代码文件，因为它们更像中间预览产物或重复内容，不适合作为当前 Android 仓库的长期文档源。
