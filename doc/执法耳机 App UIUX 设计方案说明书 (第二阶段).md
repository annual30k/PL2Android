# 执法耳机 App UI/UX 设计方案说明书 (第二阶段)

## 1. 全局视觉规范 (Visual Guidelines)

### 1.1 设计语言核心
*   **关键词**: 专业、克制、秩序、高可靠。
*   **设计原则**: 减少装饰性元素，通过间距、字重和色彩饱和度来构建信息层级。

### 1.2 色彩系统 (Color Palette)
| 类型                      | 颜色值 (参考) | 场景                           |
| :------------------------ | :------------ | :----------------------------- |
| **主色 (Tech Blue)**      | `#0057FF`     | 核心品牌色、主按钮、进度条。   |
| **背景色 (Page BG)**      | `#F4F7FA`     | 页面全局底色，略偏冷色调。     |
| **卡片/容器 (Surface)**   | `#FFFFFF`     | 内容承载面，配合微阴影。       |
| **危险/紧急 (Danger)**    | `#FF4D4F`     | SOS 状态、高危预警、退出登录。 |
| **预警/异常 (Warning)**   | `#FAAD14`     | 中级预警、设备断连提醒。       |
| **成功/在线 (Success)**   | `#52C41A`     | 设备在线、上传完成。           |
| **文本 (Primary Text)**   | `#1D2129`     | 标题、核心内容。               |
| **文本 (Secondary Text)** | `#86909C`     | 辅助信息、时间戳。             |

### 1.3 字体与圆角
*   **字体**: 优先使用 Android 系统默认字体（MiSans/Roboto），数字采用等宽字体（如 DIN）以增强专业感。
*   **圆角 (Border Radius)**: 
    *   卡片: `12px`
    *   按钮: `8px`
    *   状态标签: `4px`
*   **阴影 (Shadow)**: `0 4px 12px rgba(0, 0, 0, 0.05)` (极其微弱，仅用于区分层级)。

## 2. 核心页面设计详解

### [P01] 登录页: 专业准入感
*   **视觉定位**: 简洁、仪式感、安全感。
*   **布局建议**: 顶部占位 30% 展示科技感 Logo 或品牌 Slogan；中间部分为输入区域，底部为法律声明。
*   **重点组件**: 玻璃态(Glassmorphism)输入框（背景极浅蓝）、大圆角主按钮。
*   **状态设计**: 点击登录时，按钮变为 Loading 状态并禁用所有输入。

### [P02] 设备首页: 实时监控中心
*   **视觉定位**: 仪表盘化、数据直观。
*   **布局建议**: 
    *   **头部**: 状态摘要（例如：“执法设备已连接 · 信号良好”），背景采用深青蓝渐变。
    *   **核心区域**: 一个包含实时流媒体预览的大卡片（16:9 比例），预览窗覆盖状态标签（REC/LIVE）。
    *   **底部操作区**: 拍照、录像、对讲三个圆形大按钮，带触感反馈震动提示。
*   **设计理由**: 执法者需要最快速的操作路径。将流媒体放在视觉中心，操作按钮紧随其后，符合双手握持时的操作逻辑。

### [P05] 预警列表页: 优先级驱动
*   **视觉定位**: 高效率的任务分发中心。
*   **布局建议**: 顶部 Filter Bar 区分“待处置/已完成”。列表项采用双行布局。
*   **状态标签设计**: 
    *   **高危**: 红色呼吸光晕（呼吸灯效果）+ 警铃图标。
    *   **一般**: 橙色标签。
*   **设计理由**: 通过强对比的色彩标签，确保用户在复杂环境下第一时间识别最高优先级的任务。

### [P07] SOS 紧急页: 绝对极简
*   **视觉定位**: 强冲击力、防错触、高压下可操作。
*   **布局建议**: 全屏深红背景（或强对比黑红）。中心为巨大的倒计时圆环。
*   **核心交互**: “长按 3 秒取消” 或 “左滑确认”，防止放入口袋时误触。
*   **设计理由**: 极致的减法，排除所有干扰信息，确保用户在紧急时刻唯一的动作就是上报。

## 3. 通用组件规范 (Common Components)

### 3.1 状态标签 (Status Tag)
*   **设计**: 浅背景色 + 深文本色（例如：在线为浅绿底深绿字）。
*   **尺寸**: 固定高度 `24px`，文字 `12px`。

### 3.2 空状态 (Empty State)
*   **设计**: 灰度线稿风格图标（科技感图形，如空盒子带扫描线）+ 居中引导文案。
*   **引导**: “当前暂无设备连接，去绑定？” + 幽灵按钮。

### 3.3 加载/断连反馈
*   **断连**: 顶部下拉通知条（深橙色），常驻显示直到恢复。
*   **加载**: 线性扫描脉冲动画，而非传统的旋转圆圈，更显专业性。

---

## 4. UI 落地建议 (Android / Jetpack Compose)
*   使用 **Jetpack Compose + Material Design 3** 作为基础 UI 体系，并封装执法场景专用组件。
*   所有图标建议使用 **VectorDrawable** 或 Compose `ImageVector`，确保在不同 Android 分辨率与屏幕密度下保持清晰。
*   针对执法场景，在 App 设置中提供“高对比度模式”开关。
