# 执法耳机 App 产品需求文档 (PRD) - 需求重构与方案补全

## 1. 产品信息架构 (Information Architecture)

App 采用 **底部导航栏 (Tab Bar)** 结构，分为四大主模块，SOS 作为特殊悬浮或快捷入口。

*   **设备 (Device) - 首页**: 核心入口。处理 BLE 连接、状态显示、基础控制。
*   **预警 (Alert)**: 任务中心。接收云端推送、处置现场情况。
*   **媒体 (Media)**: 资源中心。查看/下载耳机文件、管理本地已采集文件、推流状态控制。
*   **我的 (Profile)**: 设置与个人信息、版本更新。
*   **SOS (快捷入口)**: 全局可触达的紧急上报。

## 2. 页面清单与功能区块 (Page List & Blocks)

### 2.1 登录模块
*   **[P01] 登录页**:
    *   区块：品牌 Logo、账号密码输入、服务协议勾选、登录按钮。
    *   补全：环境选择（演示/生产）、忘记密码入口。

### 2.2 设备模块 (核心)
*   **[P02] 设备首页 (已绑定)**:
    *   区块：设备状态卡片（电量、信号、在线时长）、快速控制（拍照、录像、对讲开关）、流媒体预览窗口。
    *   交互：点击进入详情，点击拍照/录像即刻下发 BLE 指令。
*   **[P03] 设备搜索与绑定**:
    *   区块：雷达扫描动画、可用设备列表（信号强度排序）、配对说明。
    *   补全：强制打开蓝牙/定位的引导逻辑、绑定失败的排查建议。
*   **[P04] 设备详情/设置**:
    *   区块：固件版本、Wi-Fi 配置（为文件传输准备）、设备名称修改、解除绑定。

### 2.3 预警与 SOS 模块
*   **[P05] 预警列表页**:
    *   区块：待处理/已处理选项卡、预警卡片（类型、等级、时间、位置）。
    *   补全：预警等级色彩化管理（红色高危、黄色预警）。
*   **[P06] 预警详情与处置**:
    *   区块：事件描述、现场照片/音频记录、处置结果选择、上报按钮。
*   **[P07] SOS 紧急上报页**:
    *   区块：倒计时触发（防止误触）、当前位置、实时录音上传、紧急联系人。

### 2.4 媒体模块
*   **[P08] 媒体管理首页**:
    *   区块：分类页签（设备端、手机端）、文件预览网格。
*   **[P09] 文件下载/上传中心**:
    *   区块：任务列表、进度条、SHA-256 校验状态。
    *   补全：存储空间预警、网络切换暂停逻辑。

## 3. 页面跳转关系 (Navigation Map)

1.  **启动** -> 登录校验 -> [登录页] 或 [设备首页]。
2.  **[设备首页]** -> 右上角 [+] -> [设备搜索与绑定]。
3.  **[设备首页]** -> 点击卡片 -> [设备详情]。
4.  **[预警列表]** -> 点击条目 -> [预警详情]。
5.  **[媒体首页]** -> 点击文件 -> [全屏预览/操作面板]。
6.  **全局** -> 长按或双击 SOS 浮窗 -> [SOS 页]。

## 4. 移动端专属 vs 硬件依赖方案补全

| 功能模块     | 移动端专属行为                           | 硬件/云端依赖        | 补全方案                                                   |
| :----------- | :--------------------------------------- | :------------------- | :--------------------------------------------------------- |
| **设备接入** | 系统权限申请(蓝牙/位置)、BLE 重连逻辑    | GATT 服务响应        | 增加“连接诊断”功能，在连接失败时自动检测蓝牙开关、距离等。 |
| **媒体管理** | 手机沙盒存储、计算文件哈希、隐形水印注入 | Wi-Fi File Service   | 引入“断点续传”与“分片上传”，防止大视频因网络波动失败。     |
| **预警执行** | 极光/个推推送、App 唤醒、本地响铃振动    | WebSocket / Web 调度 | 预警详情页集成“一键对讲”，方便现场人员快速反馈。           |
| **流媒体**   | RTSP 转 RTMP/WebRTC (中继打包)           | 媒体服务器地址       | 增加“低延时模式”开关，根据网络情况调整推流码率。           |

## 5. 待完善需求与产品化建议

1.  **Wi-Fi 切换逻辑**: 原始需求中提到 Wi-Fi File Service，通常耳机作为 AP 模式时，手机需切换 Wi-Fi。
    *   *补全建议*: 增加“自动加入设备热点”引导提示，并在文件下载完成后提醒用户切回移动网络。
2.  **数据安全性**:
    *   *补全建议*: 本地缓存文件加密存储，禁止系统相册直接查看执法敏感文件，需在 App 内通过指纹/面容解锁查看。
3.  **心跳与离线补偿**:
    *   *补全建议*: 当 WebSocket 断开时，本地记录 GPS 轨迹和日志，恢复连接后立即补发。
